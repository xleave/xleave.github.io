大多数 VLA 模型的隐含假设是：当前一帧图像 + 语言指令 = 充分的决策信息。但真实世界是部分可观测的。本文梳理 7 篇论文，分析”当前观测不够用”的场景，以及”加更多信息”时可能踩到的陷阱。

1. 时空记忆的必要性

1.1 BridgeVLA++：统一时空记忆

BridgeVLA++ 提出了一个统一的 spatio-temporal memory 框架：

同时保留 persistent spatial context（空间环境的持久记忆）和 interaction history（交互历史的序列记忆）。

这解决了一个实际问题：机器人在整理桌面时，需要记住”已经把杯子放到了左边”，即使杯子已经不在当前视野中。

1.2 FM-VLA：力历史记忆

FM-VLA 聚焦于一种特殊的历史信息——力/力矩历史：

将 force history 压缩成 memory token，使视觉相同但 contact history 不同的状态可被区分。

经典例子：螺丝拧到一半和螺丝刚开始拧，视觉画面可能完全相同，但力的历史记录完全不同。没有力历史，机器人无法判断当前应该继续拧还是停止。

1.3 记忆机制综述

Memory in Vision-Language Models 将 VLM/VLA 记忆系统组织为四个维度：

维度选项
Temporal Scope短期 / 工作记忆 / 长期
Storage内部权重 / 外部缓存 / 检索
Entity自我状态 / 物体 / 场景 / 任务
Operation编码 / 检索 / 更新 / 遗忘

该综述强调：embodied task 的 non-Markovian 性质意味着记忆不是可选的增强，而是正确决策的必要条件。

2. 本体感觉的陷阱：State-free Policy

反直觉的发现来自 State-free Policy：

Proprioception（本体感觉，如关节角度、速度等）有时会变成 trajectory shortcut，移除后反而改善 spatial generalization。

为什么会这样？因为本体感觉提供了太过精确的”当前在哪”的信息。模型可能学会了”当关节角度是 X 时执行动作 Y”这样的捷径，而不是通过视觉理解”物体在桌子的哪个位置”。当物体位置改变时，这种捷径就会失效。

3. 本体感觉到底什么时候有用？

How Should VLA Use Proprioceptive State? 系统控制了三个变量：

  • State representation：原始关节角 vs 末端执行器位姿 vs 归一化表示
  • History length：1 帧 vs 5 帧 vs 20 帧
  • Fusion interface：early fusion（与视觉一起编码）vs late fusion（在动作专家中融合）

核心发现是：

本体感觉在接触丰富和精密对齐任务中确实有用（如插入、装配），但在空间泛化要求高的任务中可能有害。

关键不是”用不用”，而是”怎么用”和”什么时候用”。

4. 视角解耦：CamVLA

CamVLA 解决了另一种”额外信息”的问题——相机外参：

将 camera-frame action 与 hand-eye transform 解耦。

传统 VLA 假设固定的相机-机器人位姿关系。CamVLA 允许相机在不同位置和角度，而不需要重新训练模型。这通过 calibration-free 的视角表示实现，提升了 camera-extrinsic shift 下的鲁棒性。

5. 价值估计中的历史条件

Robo-ValueRL 将历史信息应用到了另一个场景——价值估计：

History-conditioned value estimator 用于 offline pretraining、数据选择与 online improvement。

用历史条件化的 value function 可以更准确地判断”当前状态下继续执行的期望回报是多少”，从而在 offline 数据中选择高质量轨迹，并在 online 阶段更高效地改进策略。

6. 总结：精确的问题定义

这组论文共同挑战了两个极端假设：

假设问题
”当前一帧就够了”忽略 partial observability
”输入越多越好”引入 shortcut / 过拟合

更准确的研究问题是：

当前动作决策究竟缺什么信息？

  • 力历史：真正补充了不可观测的接触状态（FM-VLA）
  • 空间记忆：补充了视野外的持久环境信息（BridgeVLA++）
  • 本体感觉：可能补充信息，也可能只是捷径（State-free Policy）
  • 相机外参：可以通过表示设计来隐式处理（CamVLA）
